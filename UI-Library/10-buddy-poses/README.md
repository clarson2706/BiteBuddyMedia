# 10 — Buddy poses (mascot overlays)

The mascot **is** the brand — the differentiator no competitor has. These are the
14 in-app reaction poses as **transparent PNGs**, used as overlays composited on
top of UI screenshots in videos (leaning over the bezel, pointing at a UI
element, reacting).

Export effect-free pose PNGs (sparkles/confetti/glow get composited separately,
matching the in-app effect language). Source prompts + motion brief live in
`MASCOT_IMAGE_GEN_PROMPTS.md` and `Docs/Archive/FABLE_AVATAR_MOTION_BRIEF.md`.
