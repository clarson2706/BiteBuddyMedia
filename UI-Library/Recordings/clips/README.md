isolating one screen or flow so it maps to the manifest in `../../README.md`.

e.g.:
- `03-scan-capture__scan-flow.mov` (viewfinder → analyzing → result)
- `02-today-home__rings-fill.mov`
- `06-progress-weight__trend.mov`

Higgsfield-generated hook / buddy / b-roll. Tracked by Git LFS.
