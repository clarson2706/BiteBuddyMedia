# 04 — Food Result (the magic screen)

`FoodResultView` — the AI result/review screen where a photo becomes itemized
calories + macros you can edit. This is the "wow, it shows its work" moment and
appears in nearly every video concept.

| Target file | Screen |
|---|---|
| `01-food-result.png` | Itemized result — components, confidence, scan notes ⭐ |
| `02-detailed-impact.png` | "Detailed Impact" sheet |
| `03-edit-meal-totals.png` | "Edit Meal Totals" sheet |
| `04-improve-estimate.png` | "Improve Estimate" sheet |
| `05-edit-food.png` | Edit Food sheet |

Tip: use a colorful, multi-component meal so the itemized breakdown looks rich.
