## Generation cost

## Before spending paid ad dollars on any of these

1. Watch all 10, flag anything with garbled or misspelled on-screen text.
2. Consider a virality-predictor pass to rank hook strength before committing spend
   (see video 1's 28/100 hook score as the example of what this catches).
3. Get Connor's explicit go per `CLAUDE.md`'s approval gates — this folder is
   exploratory, nothing here is pre-approved for spend.
