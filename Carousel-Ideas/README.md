# BiteBuddy — Carousel / Slideshow Ideas

Ready-to-produce **TikTok Photo Mode + Instagram carousel** templates for the
launch push. Static swipe posts — near-zero production cost, currently the
highest-reach organic format on both platforms.

Grounded in `Research/CAROUSEL-MARKETING-PLAYBOOK.md` (the evidence,
the repeatable engine, and the posting schedule). Uses **real screenshots** from
`UI-Library/` and the **14 Buddy poses** in `10-buddy-poses/`.

## The four formats (rotate these)
- **`01-buddys-list.md`** — *Buddy's List* — the golf-app clone (mascot-narrated
  listicle). **The hero format.** Series-able. Hook = mistake correction.
- **`02-guess-the-calories.md`** — *Guess the Calories* — native food-TikTok
  reveal format. Massive saves. Hook = curiosity gap.
- **`03-i-was-wrong.md`** — *I was wrong about calorie apps* — confession
  carousel. Overcomes skepticism → installs. Hook = identity shift.
- **`04-one-snap-demo.md`** — *One Snap, Every Macro* — screenshot demo. Purest
  product proof; also the best Spark-Ad creative. Hook = speed/constraint.

## Shared specs (all carousels)
- **TikTok:** 9:16, **1080×1920.** **Instagram:** 4:5, **1080×1350.** Never square.
- **5–8 slides.** One idea per slide. Cover = Buddy face + 5–8 word headline.
- **Last slide is always the App Store CTA** (the golf-app move).
- Brand palette: cream `#FFF8F1`, peach `#F4A261`, deep orange `#E9843A`, sage
  `#8FA27F`, lavender `#C9C4F2` (Buddy's color).
- Add **trending audio** every post. Caption says the keyword ("AI calorie
  counter"). Pin a first comment teasing the payoff slide.
- **Guardrails:** no medical/outcome claims; estimates are informational; never
  show Meal Advisor (Coming Soon); real screenshots only.

## Deploy order
1. Lead with **F1 (Buddy's List)** + **F2 (Guess the Calories)** — most reach.
2. **F3 (I was wrong)** for skeptics / install intent.
3. **F4 (One Snap)** is the evergreen "how it works" + the paid-ad creative.
4. Each Friday: make **5–10 new cover variations** of the week's top performer
   (swap slide 1 only). That's the optimization loop.

## Canva build (do once)
Build one 8-slide master template with the palette, a locked headline text
style, and placeholder Buddy/phone-frame slots. Every new carousel = duplicate
the master, drop in poses + screenshots, swap copy. ~10 min each.
