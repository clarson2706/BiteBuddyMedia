# brand-films — finished films Connor supplies

Short, already-edited brand videos that arrive finished rather than as raw footage.
Different from `UI-Library/Recordings/`, which holds raw screen recordings the repo cuts
itself. These come in done and only need normalising and a real-UI close, which is what
`Content-Engine/build_brand_film.py` does.

## Folders

| Folder | Meaning |
|---|---|
| `_USED/` | **Already posted from.** Filed here in the same run that schedules the post, with a line in `used.jsonl`. |
| `_HOLD/` | Received but **not cleared to publish**, each with a stated reason in `used.jsonl`. A film sits here until it is re-cut or Connor overrides. |

Same rule as the recordings archive: a film moves out of the working set in the run that
consumes it, so what is left is always what still needs a decision.

## The check every film gets before it can be scheduled

Films generated by video models tend to render app UI that is *nearly* right. That is a
guardrail problem, not a taste problem, because `CLAUDE.md` says real screenshots only and
never invent UI or numbers. So each film is inspected frame by frame at full resolution
before it can be scheduled, and it lands in one of three states:

1. **Clear** — no app UI, or UI that is genuinely real footage.
2. **Acceptable** — fabricated UI present but small, blurred, or in motion, so it reads as
   stylised brand film rather than as a screenshot of the product. Schedulable, with the
   real-UI end card doing the honest work.
3. **Hold** — fabricated UI is legible. A viewer who pauses sees what looks like an app
   with typos in its own interface. Not schedulable until re-cut.

The end card is not a laundering step. It is one real frame at the end; it does not make
an earlier fabricated frame acceptable, and a film in state 3 stays in `_HOLD` regardless.

## Adding one

```bash
python3 Content-Engine/build_brand_film.py --input <film.mp4> \
    --id <YYYY-MM-DD>-<slug> --cta "<one line>" --pose <buddy pose>
```

Output lands in `Posts/Brand-Films/<id>/post.mp4` at 1080x1920 with audio preserved and
the real Today dashboard as the closing card. Then file the source here and append to
`used.jsonl`.
