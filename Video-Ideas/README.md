# BiteBuddy — Video Ideas

15-second short-form concepts for the launch push (Higgsfield). Each is grounded
in the evidence in `Research/VIDEO-MARKETING-RESEARCH.md` and uses
**real UI screenshots** from `UI-Library/`.

- **`01-the-one-that-sticks.md`** — Confession hook → screen-recording proof
- **`02-one-snap-every-macro.md`** — Silent satisfying demo
- **`03-five-ways-to-log.md`** — Listicle / fast-cut of the 5 capture modes
- **`04-i-was-wrong.md`** — Before/After (chaos → clean UI)
- **`05-meet-your-buddy.md`** — Mascot-led character/personality

## Shared specs (all concepts)
- **9:16 vertical, 720p+, 15s.** Hook text on-frame by second one.
- **First 1.5s is the whole game** — pattern-interrupt before any logo.
- **No claims** beyond the approved caption bank; **no Meal Advisor** (Coming Soon).
- Brand accents (for framing/backgrounds): peach `#F4A261`, deep orange
  `#E9843A`, sage `#8FA27F`, lavender `#C9C4F2`, cream `#FFF8F1`.

1. Lead with **C1 (confession)** + **C2 (silent demo)** for paid install intent.
2. **C5 (buddy)** is the best organic / comment-bait bet.

5. Aim for **20+ videos/month**, posted consistently (Cal AI's core lesson).
