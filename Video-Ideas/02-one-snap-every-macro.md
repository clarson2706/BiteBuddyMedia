# Concept 2 — "One snap. Every macro."

**Format:** Fast silent screen-recording demo with satisfying sound design.
**Why it works:** This is the 7-second-silent-video test — the purest
scroll-stopper. Works muted in-feed; the number count-up is the dopamine.

## Hook (0–1.5s)
Extreme close-up of a real, colorful meal; phone raises into frame.
Text snap-in: **"watch this"** + camera-shutter sound.

## 15-second beat sheet
| Time | Visual | Audio / On-screen text |
|---|---|---|
| 0–1.5s | Close-up meal, phone raises | Text: **"watch this"** + shutter SFX |
| 1.5–6s | Screen rec: photo capture → analyzing ring → food result, macros counting up (cal, protein, carbs, fat) | Satisfying "ding" as each macro lands |
| 6–10s | Food result itemized/editable components | Text: **"Every estimate itemized & editable."** |
| 10–15s | Today tab rings completing + `buddy_goal_celebration` (confetti) | Text: **"One snap. Every macro."** → end card |
